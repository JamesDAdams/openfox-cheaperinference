# openfox-cheaperinference

CheaperInference model provider plugin for OpenFox with dynamic model pricing, discount badge display, and automatic price sync.

## Features

- **Discounted Pricing**: Automatically fetches dynamic model pricing (input, output, cache read/write) and live marketplace discounts from CheaperInference.
- **Discount Toggle**: Control whether discount badges and discounted calculations are surfaced via plugin settings (enabled by default).
- **Background Sync**: Automatic background check of new models and price updates with in-app notification alerts.
- **OpenAI Compatibility**: Complete streaming and non-streaming completion support.

## Installation

```bash
openfox plugin add openfox-cheaperinference
```
